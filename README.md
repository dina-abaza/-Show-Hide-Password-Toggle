# 🔐 Show/Hide Password Toggle

This is a simple JavaScript task that allows users to **toggle the visibility of a password** input field using an eye icon.

---

## 🚀 Features

- 👁️ Show or hide password with a single click
- 🔒 Default state hides the password (as dots)
- 🧠 Uses JavaScript to toggle input `type` between `password` and `text`

---

## 🛠️ Technologies Used

- **HTML** – For input and icon structure
- **CSS** – For basic styling and positioning
- **JavaScript** – To toggle password visibility dynamically

---

## 💻 How It Works

1. User enters a password in an input field.
2. Next to the field, there's an **eye icon**.
3. When clicked:
   - If password is hidden → it's revealed (`type="text"`).
   - If password is visible → it's hidden again (`type="password"`).
4. The icon may also change (optional) between "eye" and "eye-slash".
